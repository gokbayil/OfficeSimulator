# 🎮 Office Simulator (Photon Multiplayer + Voice Chat)

Office Simulator is a Unity-based multiplayer social experience built with **Photon Engine**, allowing players to join virtual rooms, communicate through **real-time voice chat**, and interact with objects inside the environment.

This project focuses on creating an immersive multiplayer office-like space where users can meet, talk, and enjoy interactive elements together.

---

## 🚀 Features

### 👤 Player Customization (Before Joining the Game)
- Players can choose between available **pre-made character models** before entering the world.
- Users can set a custom **username**, which is displayed in multiplayer sessions.

This creates a more personalized and social multiplayer experience.

---

### 🌐 Multiplayer Room System (Photon Engine)
- Players can create or join different rooms.
- Room access can be protected with a **password system**.
- Seamless switching between rooms.

---

### 🎙️ Real-Time Voice Communication
- Integrated voice chat system using Photon Voice.
- Players inside the same room can talk instantly.

---

### 🕹️ Interactive Environment
The office space includes interactable objects to enhance immersion:

#### 🎵 Jukebox Interaction
- Players can interact with the jukebox.
- When activated, it plays music inside the room.

#### 📺 Television Interaction
- A functional TV object that can be interacted with in-game.

---

## 🛠️ Built With

- **Unity Engine**
- **Photon PUN 2** (Multiplayer Networking)
- **Photon Voice** (Voice Chat)
- Custom Interaction System

---

## 📌 Project Goal

The main goal of this project is to build a multiplayer social environment where users can:

- Select a character and username before joining
- Join private or public rooms
- Communicate naturally with voice chat
- Interact with shared objects in real time

This project demonstrates skills in networking, multiplayer synchronization, and interactive gameplay systems.
